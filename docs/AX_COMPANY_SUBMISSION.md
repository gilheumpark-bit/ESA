# ESA AX 아이템 — 설치된 AI를 전기 도면 검토 업무로 연결

기준일: 2026-09-07. 이 문서는 회사 내부 제안·파일럿 평가용이며 판매 실적, 독립 실도면 정확도 또는 운영 승인서를 대신하지 않는다.

## 제안 요약

**아이템명: AI 기반 전기 도면 검토·근거 추적 업무 도구**

이미 연결된 AI가 기기·문자·배선을 읽고, ESA가 중복을 정리하고 연결 관계와 계산 근거를 구조화한다. 실무자는 기존 결과 화면과 보고서에서 기기·결선·확인 항목을 원본과 대조한다. 이번 개선은 AI 계정 연결을 새로 만드는 사업이 아니라 **AI 판독 결과를 실제 업무에 쓰기 좋게 만드는 정밀도 개선**이다.

대상 업무는 전기 설계·공사·설비 관리의 도면 1차 검토다. 담당자가 수작업으로 기기 목록과 결선을 다시 맞추는 부담을 줄이는 것이 목표이며, 최종 설계 승인과 현장 안전 판단의 책임을 소프트웨어로 이전하지 않는다.

## 이번에 구현한 개선과 업무 가치

| 구현 | 해결하는 문제 | 기대하는 업무 효과 |
|---|---|---|
| 판독 후보·원본 좌표 단자 보존 | AI가 읽은 후보와 접속 위치가 변환 단계에서 사라짐 | 동일 내용을 다시 읽는 대신 기존 근거로 판단할 기회 확대 |
| 본체·조각 병합의 비교 순서 수정 | 작은 조각을 먼저 읽으면 뒤의 온전한 본체 판정이 복구되지 않음 | 본체 근거가 충분한 기기의 판정 복구 |
| 단자 접촉 우선 결선 | 기기 상자를 통과한다는 이유로 무관한 기기가 연결됨 | 존재하지 않는 결선에 대한 재확인 부담 축소 |
| 페이지·명판 경계 보존 | 페이지가 다른 동명 기기, TR-1과 TR-10의 잘못된 병합 | 기기 누락·잘못된 수량 집계 방지 |
| 굽은 배선 경로 비교 | 끝점이 같지만 경로가 다른 배선을 하나로 병합 | 서로 다른 실제 배선의 기하 정보 보존 |
| 자동 회귀 검사와 Jest 연결 | 수정한 결함이 후속 개발에서 재발 | 반복 검증 가능한 납품·유지보수 근거 |

효과는 구현 의도다. 업무시간 절감률과 실도면 정확도 개선 폭은 아직 측정하지 않았다. 이번 변경은 AI 호출 경로, 모델, 계정, 결제 또는 외부 전송 대상을 추가하지 않는다. 처리시간과 총비용은 실제 파일럿에서 별도로 측정한다.

## 현재 확인한 증거

동일한 합성 회귀 시나리오 25개를 기존 기준선과 수정 코드에 실행했다. 기존 기준선은 10개 통과·15개 실패, 수정 코드는 25개 통과·0개 실패다. 기기 후보·단자 보존, 본체 판정 복구, 오병합, 배선 경로와 64개 독립 합성 피더의 정확한 기기쌍을 검사한다.

**이 결과는 선택한 결함·기능 계약의 통과 여부다. 도면 정답률 100%, 현장 사고 감소율 또는 독립 실도면 성능 향상률이 아니다.** 실행 환경·명령·미실행 항목은 [개발 인수인계](project/handoffs/2026-09-07-ax-precision.md)에 기록한다.

## 회사 시연 흐름

이미 승인된 AI 연결을 유지한 상태에서 공개·합성 DXF/PDF 또는 반출이 승인된 도면을 사용한다. 기존 도면 분석 화면에서 파일을 분석하고, 기기·결선 결과를 원본과 대조한 뒤 보고서의 근거를 확인한다. 원본에 없는 전압·전류·규격을 임의 입력해 시연 점수를 만들지 않는다. 실제 회사 도면은 공개 GitHub나 승인되지 않은 외부 AI로 올리지 않는다.

시연의 핵심은 화려한 답변이 아니라 **같은 기기를 중복 집계하지 않는지, 다른 기기를 지우지 않는지, 올바른 단자에 배선이 연결되는지**다. 이번 변경은 기존 화면이 소비하는 분석 데이터를 개선하며 별도의 신규 대시보드나 새 보고서 UI를 추가한 것은 아니다.

## 파일럿 평가 설계

최적화에 사용하지 않은 도면을 형식·밀도·품질별로 나눠 고정한다. 같은 원본의 PDF와 PNG는 동일 묶음으로 취급해 학습·조정용과 평가용에 나눠 넣지 않는다. 기존 방식과 개선 방식을 같은 자료·AI 설정·호출 예산으로 비교하고, 정답 판정은 업무 담당자의 원본 대조로 작성한다.

| 지표 | 측정 방법 |
|---|---|
| 기기별 정밀도·재현율 | 수량 합계가 아닌 위치·기기 식별자를 맞춰 오탐·누락·중복을 측정 |
| 결선 정밀도·재현율 | 실제 연결된 기기·단자쌍과 비교; 관계 개수만으로 평가하지 않음 |
| 올바른 자동 확정 비율 | 정답 중 자동 확정된 비율과 잘못 확정된 항목을 함께 기록 |
| 검토 소요시간 | 업로드·AI 대기·수정·원본 확인을 포함한 전체 시간의 중앙값과 상위 구간 |
| 문서당 비용 | AI 사용량·실행 비용·검토자 재작업 비용을 분리 기록 |

목표값은 파일럿 시작 전에 회사가 정하고 평가 후 바꾸지 않는다. 우선 통과 조건은 잘못 확정하는 오류를 늘리지 않으면서 올바른 기기·결선 회수와 검토시간이 개선되는지다.

월간 순효과의 계산식은 다음과 같다. 측정되지 않은 입력은 빈칸으로 남긴다.

> 월 처리 도면 수 × 도면당 절감 시간(분) ÷ 60 × 시간당 업무비용 − 월 추가 AI·인프라·운영비

이 계산은 생산성 추정이며 실제 인건비 감소나 매출 발생을 의미하지 않는다.

## 도입·사업화 범위

첫 적용은 기존 AI가 준비된 팀의 내부 파일럿이다. 검증 후 회사 심볼 사전, 배포·교육·운영 지원과 연계하는 제품화를 검토할 수 있으나 이번 커밋에서 유료 결제, 회사별 권한 관리 또는 운영 배포를 완료한 것은 아니다.

기존 저장소의 라이선스·저작권·데이터 권리는 변경하지 않았다. `package.json`의 라이선스 표시는 `CC-BY-NC-4.0`이다. 회사 제출과 외부 유료 판매·재배포의 권리 판단은 구분하고, 외부 사업화 전에 권리자와 회사 담당자가 적용 범위를 확인해야 한다.

외부 AI 실호출, 전체 빌드·CI, 회사 환경의 보안·저장·권한 검증은 통합 배포 전에 확인한다. 자세한 현재 제품 경계는 [README](../README.md)와 [검증 원장](VALIDATION_EVIDENCE.md)을 따른다.
