# 2026-09-08 도면 분석 업무 제품화 개선

## 기준과 구현 범위

출발점은 PR #71의 `17049837252203d67d798ca3fb2f2a6abfa8dee5`다. 기존 AI 연결을 유지하고 도면 판독의 **연결 복원 → 중단 후 재개 → 원본 대조 → 보고서 반출** 경로를 개선한다. 모델·추론 수준·요금·인증·회사 도면 반출 정책은 바꾸지 않는다. 유료 출시 승인이나 실도면 정확도 인증을 이 변경만으로 주장하지 않는다.

## 생산 코드 변경

| 변경 | 생산 경로 | 확인할 동작 |
|---|---|---|
| 분할 배선의 단자 경로 복원 | `buildPageRelations` → `resolveTerminalPaths` | 관측 선이 실제로 이어지고 두 기기의 단자가 유일하게 결박된 회로를 복원한다. `lineIds`에 전체 경로, `terminalPath`에 단자 좌표, `evidence`에 모든 구간 출처가 남는다. |
| 접점과 비접속 교차 분리 | `buildConductorAdjacency` | 비접속 교차 표식을 무시해 선망을 합치지 않는다. 표시용 직선(`synthetic`)과 실제 관측 기하를 분리한다. |
| 완료 페이지의 판독 보존 | `document-orchestrator` → `restoreCompletedPageEvidence` | 완료 노드를 원시 판독으로 되돌리지 않는다. 판정된 타입과 남은 후보·단자·원본 근거 ID를 복제 보존한다. 새 판독만 병합하며 이전 저장 객체를 변형하지 않는다. |
| 경로 전체 원본 대조 | 관계 탭 → SVG 오버레이 | 관계 선택 시 한 조각이 아니라 경로에 속한 선을 함께 강조하고 전체 선로 번호를 보여 준다. |
| 업무용 보고서 | `export-drawing-document` | 기기명·전체 선로·정격·계산 결과와 영수증·페이지 간 참조·보류·권장 조치를 함께 출력한다. 도면 해시·갱신 시각·페이지·근거 ID를 포함한다. |
| 인쇄·CSV 동작 수리 | `openDrawingPrintWindow`, `/tools/sld` | 사용자 클릭 안에서 빈 창을 열고 즉시 opener를 끊은 다음 보고서를 만든다. 오류 시 빈 창을 정리하며, 전체 문서 입력도 동일 파일을 다시 선택할 수 있다. |

그래프 버전은 `evidence-graph-continuity-v8`로 갱신해 구버전 조립 결과를 새 결과로 재사용하지 않는다. 스키마 3의 새 필드는 선택 사항이다. 기존 보고서와 단자 없는 입력은 계속 읽으며, 기존 추론 관계를 전면 삭제하거나 자동 확정으로 바꾸지 않는다.

복원 범위는 **확정 관측 기하의 유일한 두-기기 단자 경로**다. 갭·합성선·타입 미상 선·모호 판독·서로 겹치는 단자·기기 몸체 관통·미확정 분기에서는 새 확정을 만들지 않는다. 세 단자 이상인 모선망을 임의 연결 트리로 확정하는 기능이 아니다. 기존 2px 단자 접촉 허용범위와 불확정 갭 복원 범위를 늘리지 않았다. 길이·전류 방향·설계 적합성은 이 기하 증거만으로 추정하지 않는다.

## 보고서 완전성과 파일 안전

종전의 5,000행 절단을 없앴다. 50,000행까지 모두 반출하며 그 이상이면 항목을 숨긴 파일 대신 명시적인 오류를 낸다. 비정상적으로 긴 셀은 표시 생략 사실을 명시한다. CSV에는 공백·제어문자·전각 접두를 포함한 수식 실행 표식을 텍스트로 처리하고, 인쇄 HTML의 외부 입력은 이스케이프한다. 원본 도면을 새 서버로 보내지 않는다. 문서 해시는 원본 식별용이며 출력물 전체에 새 법적 전자서명을 부여한 것은 아니다.

## 로컬 검증

Node 22.16.0과 설치된 TypeScript 5.8.3 transpiler로 **실제 생산 모듈**을 임시 변환해 검사했다. 프로젝트의 정본 TypeScript 버전·전체 타입 검사·Next 빌드를 대신하지 않는다.

```bash
node --test --test-reporter=tap scripts/lib/drawing-commercial.node-test.mjs
node --test --test-reporter=tap scripts/lib/ax-precision.node-test.mjs
npm run check:docs
git diff --check
```

같은 신규 계약 38개를 출발점과 수정 코드에 적용했다. 출발점은 13개 통과·25개 실패, 수정 코드는 38개 통과·0개 실패다. 기존 AX 정밀도 계약도 25개 통과·0개 실패다. 신규 검사는 **64개 독립 분할 합성 회로의 정확한 기기쌍**, 전체 배선 근거 보존, 접속/비접속/모호 분기, 재개 복제 보존, CSV 수식 방지, 5,100행 마지막 항목, 과대 반출 오류를 포함한다. 이 비교는 선택한 기능·결함 계약이며 독립 실도면 정답률이나 시간 절감률이 아니다.

Jest 진입점에 새 계약을 연결했고, 기존 전체 문서 재개 통합 검사에 판정·후보·단자·출처 보존 단언을 추가했다. 인쇄 창 동작 단위 검사와 1440px/390px 브라우저의 관계 선택·CSV 다운로드·인쇄 창 검사를 추가했다. 화면 검사는 명시적 합성 HTTP 응답을 사용한다. 실제 PDF/DXF 게이트는 별도로 그대로 유지한다.

전체 타입·린트·Jest·빌드·PDF·브라우저 결과는 **이 문서를 포함한 정확한 후속 커밋의 PR #71 CI 기록**으로 확인한다. 이전 `17049837`의 녹색 결과를 이번 코드의 통과 증거로 사용하지 않는다.

## 상업 출시 전 남는 판정

기존 공개 교보재 실증은 [검증 원장](../../VALIDATION_EVIDENCE.md)에 있다. 이번 작업은 그 실증을 없었던 것으로 취급하지 않으며, 새로운 실제 AI 호출이나 회사 비공개 도면 평가를 수행한 것은 아니다. 추가된 단자 확정 규칙은 사용자의 대표 도면과 독립 정답을 사용해 결선 정밀도·재현율·잘못 확정한 연결·검토시간을 평가해야 한다. 부하가 큰 도면의 지연·메모리, 회사 운영 환경의 권한·저장·보안은 별도 승인 항목이다.

판매용 라이선스를 바꾸지 않았다. 현행 CC-BY-NC-4.0 권리 검토, 회사 심볼·도면 사용 권한과 실제 배포 검증은 외부 유료 제공 전에 별도로 처리한다. 이번 작업은 PR 브랜치에 반영하며 `main`/운영 환경을 자동 배포하지 않는다.
