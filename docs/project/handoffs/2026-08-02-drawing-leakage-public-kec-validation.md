# 도면 누수·공개 교보재·KEC 검증 인수인계 — 2026-08-02

## 결론

이번 배치는 **누수를 전부 제거했다는 증거가 아니다.** 파서가 정상 응답을 버리거나, 실패 원인을 숨기거나, 비회로 면에 기기를 발명하거나, 같은 종류의 보완 제안을 수백 건으로 부풀리던 누수는 수리했다. 그러나 반복 기호가 많은 배전도에서 일부 부하와 연결을 놓치는 공간 관계 누수, 설치 조건이 없는 케이블에 KEC 적합을 단정할 수 없는 규정 입력 누락은 남아 있다.

현재 판정은 다음과 같다.

- 공개·국내 교보재의 **수량·기호 판독**: 일부 성공, 일부 누락. POC 비교와 회귀에는 사용 가능하다.
- **관계도 완전 복원**: HOLD. 북미 배전도와 고밀도 MCC에서 연결 누락이 재현됐다.
- **KEC 전면 적합성 판정**: 미구현. 현재 자동 검토는 일부 규칙만 다룬다.
- **95% 정확도 주장**: HOLD. 독립 인간 정답과 서명된 외부 평가 영수증이 없다.

## 평가 좌표와 스냅샷

- 대상: ESA 도면 분석 production 경로와 V3 독립 심사 경로
- 상태: `main` HEAD `4ed7d0e2fd14f58caee40281366af2f6feac67c5` 기반 작업 트리
- 검증 모드: 절대 판정이 아니라 결함 재현·수리 전후 차분
- 렌즈: vision parsing, spatial topology, electrical review, KEC scope, UI disclosure
- 교보재: 저장소·로컬에 확보된 공개 단선도, 북미·유럽 배전도, 실제 결선도, 국내 배전반·MCC·삼선결선도·비회로 배치도, PDF 생산 fixture
- 주의: 아래 수동 수량표는 이번 작업에서 도면을 직접 세어 만든 **잠정 라벨**이다. 독립 인간 이중 판정이 아니므로 95% 주장용 golden label로 사용하지 않는다.

### V3 독립 심사 경로

고밀도 MCC를 5역할로 심사했을 때 초기에는 45회 호출 뒤에도 역할 2개가 실패하고 추천이 212건까지 늘어났다. 실패 진단, 응답 정규화, 역할 시간 예산, 추천 집계를 수리한 뒤에는 역할 결과가 부분 복구되고 동일 원인의 권고가 6개 묶음으로 줄었다. 최종 라이브 재실행에서 남은 실패는 coverage auditor의 실제 미해결과 `symbol.bounds.pageIndex` 별칭이었다. `pageIndex`는 정규화 코드와 단위 테스트로 수리했으나, 그 수정 뒤 비용이 큰 V3 라이브 재실행은 아직 하지 않았다.

따라서 V3는 “실패 원인을 숨기는 경로”와 “권고 폭증”은 개선됐지만, 이번 스냅샷에서 `COMPLETE`를 주장하지 않는다.

## 수리한 누수

1. 반복 심볼을 하나의 집계 기기로 반환하지 않도록 역할 프롬프트와 `parallelCount` 계약을 보강했다.
2. 비회로 배치·치수 면은 회로 기기를 발명하지 않고 빈 결과로 반환하도록 했다.
3. 고압/중압 변전소의 겹친 권선 기호를 영역 라벨만 보고 전원으로 바꾸지 않도록 기호 우선 판독 규칙을 넣었다.
4. V3 역할 실패를 일반 오류로 덮지 않고 timeout, 절단 JSON, 루트 배열, 잘못된 bounds 필드까지 안전하게 기록한다.
5. `[x,y]` 점 좌표, 닫힌 항목까지만 있는 절단 JSON, 역할 루트 배열을 confidence 페널티와 함께 부분 복구한다.
6. bounds의 0-based `pageIndex`를 정본 `page`로 변환하고 충돌·지원하지 않는 필드는 닫는다.
7. 같은 페이지·같은 원인의 고아 기기, OCR, 연속성 권고를 그룹화하되 모든 대상 ID와 근거는 보존한다.
8. 로컬 도면 영수증이 재생 경로에서 review, calculation chain, topology, saga를 잃던 문제를 막았다.
9. UI에 현재 KEC 자동 검토 범위와 **KEC 전면 검토가 아님**을 항상 표시했다.

## KEC 자동 검토 범위

2026-01-05 시행 KEC가 현행 기준이다. 공식 목차에서 과전류 보호는 212.4(과부하), 212.5(단락), 212.7(보호장치 협조), 배선 허용전류는 232.5로 분리돼 있다.

### 현재 자동화됨

- 차단기 AF/AT 구조 관계 검사
- 케이블 단면적·도체·절연·설치 방식과 전류가 모두 있거나 제한된 기본 가정을 명시할 수 있을 때 KEC 허용전류 대조
- 병렬 케이블에서 포설·집합 조건이 없으면 HOLD
- 변압기 용량·전압으로 2차 정격전류 교차 계산
- 필요한 입력이 없을 때 `DATA-GAP/UNKNOWN`으로 닫기

### 현재 누락 또는 불완전

- 212.5: 예상 단락전류와 차단용량의 직접 비교
- 212.7: 상·하위 보호장치 협조와 선택차단
- 감전 보호, 접지·보호도체 연속성, 접지저항 판단
- 전압강하, 케이블 단락 내량, 온도·집합·포설 보정의 완전한 증거 결박
- SPD·피뢰·서지 협조
- 전동기 과부하·단락·결상 보호

현재 가장 큰 규정 누수는 단일 케이블의 설치 방식·주위온도·집합회로 수가 없는 경우다. 기존 코드는 제한된 기본 조건으로 허용전류를 계산할 수 있지만, 그 결과를 무조건적인 KEC 적합으로 읽으면 안 된다. 다음 구현은 connection/spec 계약에 `installationMethod`, `ambientTemperature`, `groupedCircuitCount`와 출처 ID를 넣고, 하나라도 근거가 없으면 **조건부 결과 또는 HOLD**로 내려야 한다.

## 남은 결함과 다음 순서

1. **공간 관계 누락**: 북미 배전도 부하 1개와 하위 연결 다수, 고밀도 MCC 분기 연결 다수가 누락된다. 전체 이미지→4×4 구획→반복 기호 전용 재스캔→전역 중복 제거를 V3 실경로로 비교해야 한다.
2. **정답 독립성**: 잠정 수량표를 전기 실무자 2인 블라인드 라벨로 교체하고, 불일치는 합의 로그로 남겨야 한다.
3. **KEC 입력 계약**: 설치 조건, 고장전류, 차단용량, 보호장치 곡선과 출처 ID를 그래프에 추가한다.
4. **제안 품질**: `UNKNOWN` 입력을 설계 변경 명령으로 승격하지 말고, 확인 요청→계산→보호 협조→수정 제안 순으로 출력한다.
5. **내구 영수증**: 운영에서는 `DRAWING_JOB_STORE_DIR`을 필수화하고, 동기 익명 분석도 브라우저 응답 유실 뒤 다시 읽을 수 있는 durable receipt writer가 필요하다.
6. **V3 재실행**: `pageIndex` 정규화 수정이 적용된 동일 MCC 도면을 다시 호출해 5역할 결과와 coverage auditor만 남는지 확인한다.

## 재실행 명령

```powershell
npm run test:drawings -- --runInBand
npm run gate:pdf
npm run gate:sld-v3-contract

npm test -- --runInBand
npx tsc --noEmit --incremental false
```
