## 구현

`team-result-adapter.ts`는 모든 타입 후보와 원본 좌표 단자를 `RawSymbolHit`에 전달한다. `evidence-deduplicator.ts`는 후보·단자를 병합 후에도 유지하며, 명시적으로 모호한 판독을 자기확신 점수만으로 확정하지 않는다. 단자가 없는 기존 문서의 연결 경로는 유지한다.

본체·조각 충돌에서는 새 근거를 추가하기 전의 최대 면적을 비교하도록 수정했다. 기존에는 새 본체까지 최대 면적에 포함해 본체 우위 조건이 성립할 수 없었다. 충분한 확정 본체가 들어오면 작은 모호 조각의 판정을 복구하되, 비슷한 몸체의 실제 타입 충돌은 보존한다.

명판 병합에는 같은 페이지와 영숫자 경계를 적용한다. 굽은 배선은 끝점만이 아니라 경로를 양방향 비교한다. 단자가 존재하는 기기는 실제 단자 접촉을 우선하며, 몸체 상자의 우연한 교차로 연결하지 않는다. 여러 기기에 겹치는 단자 관측은 임의 ID 순서로 확정하지 않는다. 기존 추론 브리지·최소 신장 트리 관계는 여전히 모호 상태이며 전체 연결 정의를 통합한 것은 아니다.

## 자동 검사 연결과 남은 검증

`src/agent/drawing/__tests__/ax-precision-contract.test.ts`가 동일 검사를 실행하도록 추가했다. 기존 Jest/CI 경로에서 새 계약이 실행되도록 등록한 것이며, 이 작업 환경에서 전체 Jest를 실행했다는 의미는 아니다. 기존 `test:scripts`의 파일 패턴으로도 실행된다.

```bash
npm run test:scripts
npm test -- --runInBand ax-precision-contract
npm run check:docs
npx tsc --noEmit
npm run lint -- --max-warnings=0
npm test -- --runInBand
npm run build
npm run gate:pdf
```

위 통합 명령, 브라우저 E2E, 외부 AI 실호출과 독립 실도면 재생은 이 작업 환경에서 실행하지 못했다. 네트워크를 통한 전체 의존성 설치가 되지 않아 로컬 검증을 해당 모듈의 Node 계약으로 한정했다. GitHub Actions의 결과는 PR의 실제 실행 상태를 확인하고 별도로 판단한다. 이 문서를 CI 통과 증거로 사용하지 않는다.
