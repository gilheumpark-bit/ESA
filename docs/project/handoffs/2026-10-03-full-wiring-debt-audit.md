- **소유자 결정이 필요한 것** — [휴면 대장](../../DORMANT_MANIFEST.md)의 평면도팀(제거 vs 구축), 기준팀
  일반 검색 분기(성공으로 셀지), 다중팀 보고서 서버 저장(보관 기간), 브라우저 오류 수집, 프로젝트 승인 흐름.
  [부채 대장](../../TECHNICAL_DEBT.md)의 `DEBT-DRAW-001`(어휘 통일 — 보류가 줄어드는 변경).

  `DEBT-DEP-001`, `DEBT-TEST-001`, `DEBT-DRAW-002`.
- **고칠 수 없었던 것** — `.env.example` 은 이 작업 환경의 편집 차단 대상이라 건드리지 않았다. 예제에
  없는 키와 예제에만 있는 키의 차이는 다음 작업으로 남는다.

## 3. 검증

- `npx tsc --noEmit`, `npm run lint -- --max-warnings=0`, `npm test -- --ci --forceExit`,
  `npm run test:scripts`, `npm run check:docs`, `npm run gate:hygiene`, `npm run gate:snapshot` —
  커밋마다 한 사슬로 실행하고 종료 코드 0 에서만 커밋했다. 개수는 PR 설명과 CI 를 따른다.
- 마이그레이션 011 은 이 PC 에 PostgreSQL 이 없어 로컬에서 적용하지 못했다. `scripts/db/lifecycle-test.sql`
  에 권한·정책·트리거 확인을 넣었고 CI 의 Database lifecycle 작업이 실제 PostgreSQL 16 에서 실행한다.
  **운영 DB 에는 적용하지 않았다** — 배포 절차로 따로 적용해야 한다.
- 새 화면(계산 추가·공유 링크 회수·답변 채택)은 단위·배선 테스트까지다. 로그인 상태의 실제 클릭
  왕복은 운영 자격증명이 필요해 하지 않았다.
- 실제 외부 AI 호출, Stripe, Weaviate 는 이번 범위 밖이다.
