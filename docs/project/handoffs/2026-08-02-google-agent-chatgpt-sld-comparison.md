# Google Agent Platform·ChatGPT 5.6 SLD 모델 비교 및 수리 영수증

## 평가 좌표

- 대상: ESA 생산 진입점 `POST /api/sld`의 공개 단선도 판독
- 상태·모드·렌즈: 수리 후 커밋 스냅샷 · benchmark/delta · technology/integration/research
- 단계: I 구현 + X 통합 실호출 + 제한된 V 실증
- 코드 기준: `f481d913ec5057ece7651875ed532c4c50e42f16`
- 실행일: 2026-08-02 (Asia/Seoul)
- 공개 입력: `fixtures/drawings/external/wiki-oneline.png`
- Google 경로: Agent Platform Express Mode, `GOOGLE_VERTEX_API_KEY`
- ChatGPT 경로: 로컬 Codex 공식 ChatGPT 로그인(Pro), Platform API 키 없음

이 영수증은 공개 단선도 한 장에 대한 동일 입력 반복 실측이다. 독립 데이터셋
정확도나 범용 80% 달성을 증명하지 않는다.

## 추론 강도

- 최초 비교는 추론 강도를 요청에 넣지 않았다. 로컬 app-server 모델 메타데이터상
  기본값은 Luna `medium`, Terra `medium`, Sol `low`여서 공정한 비교가 아니었다.
- 수리 후 ChatGPT SLD 호출은 세 모델 모두 `turn/start.effort = medium`으로 고정했다.
- Google Agent Platform 경로는 현재 ESA 요청 계약에 별도 reasoning-effort 필드가
  없어 각 Gemini 모델의 공급자 설정을 사용했다.

## 사람이 확인한 표본 기준

기기는 외부계통 연계점 2, 차단기 6, 모선 3, 발전기 1, 3권선 변압기 1,
분로 리액터 1로 총 14개다. 결선은 13개다. 전력 흐름 문자는
`75 MW/23 MVAR`, `85 MW/27 MVAR`, `200 MW/96 MVAR`, `40 MW/46 MVAR`,
`39 MW/21 MVAR`의 5묶음이다.

이번 자동 판정은 기기 수·종류, 결선 수, 단일 연결망, 고립/인라인 절단,
구조화된 MW/MVAR 묶음 수를 확인했다. 모든 간선의 끝점 identity를 독립 정답표와
일대일 비교한 것은 아니므로 관계 정확도 일반화는 보류한다.

## 실패 원인과 수리

1. SLD 타입 계약에 `reactor`가 없어 리액터가 `load` 또는 `capacitor`로 밀렸다.
2. 도면 밖 송전망 경계를 표현할 타입이 없어 전력 화살표 방향에 따라 `source`나
   `load`로 강제됐다. import/export 양쪽이 가능한 `grid_connection`을 신설했다.
3. 연결 계약에 유효전력·무효전력·방향 필드가 없어 값이 기기 라벨·주석·설명으로
   흩어졌다. `activePower`, `reactivePower`, `flowDirection`을 추가했다.
4. 인라인 차단기·개폐기·퓨즈의 양쪽 연결과 bus-tie 분할 규칙이 약해 한쪽 선로가
   끊겨도 통과했다. `DANGLING_INLINE_DEVICE` 검증을 추가했다.
5. GPT 추론 강도가 모델 기본값에 맡겨져 Sol만 `low`였다. 세 모델을 명시적
   `medium`으로 통일하고 SLD 제한 시간을 180초로 늘렸다.
6. Sol 재시험에서 한 번 인쇄된 MW/MVAR가 차단기 양쪽 간선에 복제돼 5개가
   9개로 부풀었다. 인라인 기기 양쪽의 같은 전력 쌍을
   `DUPLICATE_FLOW_MEASUREMENT`로 HOLD하고 화면에 수량을 노출했다. 프롬프트에도
   한 인쇄 표기는 한 연결에만 기록하도록 명시했다.
7. 같은 어휘를 래스터 VLM에만 넣지 않고 PDF 벡터와 DXF 블록 사전, 결과 화면까지
   연결했다.
8. 서버가 `to_from`을 보존해도 화면 화살표는 항상 `from → to`였던 마지막 배선
   오류를 고쳤다. 역방향은 끝점을 뒤집고 양방향은 별도 화살표로 표시한다.

## 현재 결론

- 이 표본에서 Gemini 3.1 Pro와 3.6 Flash는 2/2 구조 게이트를 통과했다. 3.1이
  더 빨랐지만 한 장 결과로 기본 모델을 교체할 근거는 부족하다.
- GPT 중 Terra가 2/2 안정적이었다. Sol은 최초 중복 편차가 있었으나 계약·게이트
  수리 후 표적 재시험 2/2를 통과했다.
- Luna는 1/2회 핵심 결선 누락과 리액터 오분류가 있어 단독 최종 판독기로 쓰지
  않는다. 다만 제품 게이트가 해당 회차를 정상으로 위장하지 않고 HOLD했다.
- 권장 배선은 `빠른 1차 판독 → 독립 GPT 심사 → 전체 그래프 병합·중복 제거 →
  고립·인라인 절단·전력표기 중복 HOLD`다.

## 미검증 범위

- 다른 공개 도면과 초급·중급·고급 난이도별 반복
- 독립 정답 간선표 기반 edge identity precision/recall
- OCR 문자 단위 정확도와 화살표 방향의 좌표 기반 정답 대조
- 계산기 제안 입력값 정확성 및 규정 교차검증
- 장시간 반복 시 한도·비용·timeout 분포

따라서 범용 80% 정확도 주장은 독립 정답표가 있는 복수 공개 도면에서 모델별
3회 이상 반복하기 전까지 HOLD다.
