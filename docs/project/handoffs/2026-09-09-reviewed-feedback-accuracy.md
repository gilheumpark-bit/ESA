# 2026-09-09 사람 정정 재사용과 정격·결선 정확도 개선

## 기준과 목적

출발 제품은 PR #71의 `d73a19b5318d2a39ea80f02b62eba0429b44955b`다. 사람의 정정을 현재 문서에만 저장하던 경로를 다음 DXF의 제한된 분류 근거로 연결한다. 동시에 기존 상업성 진단에서 확인한 정격 귀속·페이지 연결의 오확정을 줄인다. 임의 확정이나 전 항목 HOLD로 시험을 통과시키지 않는다.

이 문서는 설계와 검사 계약을 기록한다. 정확한 반영 커밋·실행 결과는 이 변경의 CI 및 PR 검증 댓글을 확인한다. 작성 시점에 미실행인 검사를 완료한 것으로 나타내지 않는다. main 병합·운영 배포는 포함하지 않는다.

## 두 종류의 피드백을 분리

현재 문서의 정정은 기존 `applyDrawingCorrection`과 서버 소유권·문서 버전 검사를 그대로 사용한다. 종류·문자·이름 수정, 영향받는 계산 무효화, 수정 전후 이력과 `goldenEligible:false`는 유지한다.

다음 분석의 재사용은 별도 승인 절차다. 현재 문서에 실제 반영된 최신 종류 정정, 알려진 기기 종류, 유일한 DXF 블록 원본 지문이 있을 때만 후보로 만든다. 문자·정격·결선·unknown 선택을 심볼 종류 규칙으로 일반화하지 않는다. 모델 JSON에 적힌 가짜 지문·피드백 ID는 일반 판독 파서에서 수용하지 않는다.

흐름:

`현재 DXF 정밀 결과의 종류 정정 → 원본 위치 확인 → 회사와 정정 이유를 넣어 후보 저장 → 명시적 적용 승인 → 다음 DXF에서 회사·블록명·정규화 형상이 모두 일치할 때 적용 → 승인 철회 또는 원래 정정 변경 시 재사용 중지`

## 적용 범위와 충돌 처리

승인 사례는 기존 심볼 라이브러리 계약의 `fingerprint-and-name` 규칙으로 컴파일한다. 종전 수동 라이브러리는 유지하지만, 피드백 규칙 자체는 이름만 또는 지문만으로 일반화하지 않는다. 같은 패턴의 승인 사례나 기존 회사 사전이 서로 다른 종류를 주장하면 첫 항목/마지막 항목을 고르거나 전역 이름 휴리스틱으로 넘어가지 않고 미판독과 충돌 이유를 남긴다.

적용된 결과에는 `appliedFeedbackIds`, 원본에는 `sourcePattern/sourcePatterns`가 있어 어떤 승인 사례가 분류에 관여했는지 추적한다. 같은 지문이라도 서로 다른 블록명은 별도 범위다. INSERT의 위치·회전 변경은 블록 정의 지문과 구분한다.

피드백 승인은 이 브라우저 검토자의 명시적 선택이다. 조직 관리자 승인이나 서버 권한 정책을 추가한 것이 아니다. 회사별 분리·저장 버전·가져오기 재승인·철회를 제공하지만 localStorage의 revision 검사는 다중 사용자 트랜잭션이 아니다. 다른 탭의 storage 이벤트를 반영하고, 알려진 오래된 버전의 저장은 거절한다.

JSON 가져오기는 승인 상태를 승계하지 않고 대기로 바꾼다. 기존에 내보낸 컴파일 사전 역시 현재 로컬 승인 사례가 없으면 해당 feedbackId의 권한을 승계하지 않는다. 손상된 저장 내용을 자동 덮어쓰지 않는다. 저장 실패는 화면 오류로 알리고 해당 세션의 자동 적용을 중지한다. 다른 PC에 이미 복사된 파일까지 원격으로 철회하는 기능은 아니다.

## 정확도 개선

### 정격 판독과 귀속 분리

공통 물리량 파서가 한 문자 블록의 여러 값을 각각 추출한다. 숫자의 범위와 단위 경계를 확인해 kVA를 kV로 해석하지 않고 대소문자를 정규화한다. 기존 downstream 필드명 voltage/capacity/current/breakingCapacity/power/size는 유지한다.

정격값은 원문·정규화값·문자 판독 상태와 별도로 기기 귀속 상태·후보·이유를 갖는다. 같은 페이지의 유일한 명시적 기기 태그 또는 유일하게 둘러싼 기기 근거는 귀속 근거가 될 수 있다. 단순 근접은 후보이며, 동률·복수 후보·멀리 떨어진 값·잘못된 좌표는 임의의 기기 ID로 채우지 않는다. 읽힌 수치는 계속 보존한다.

이는 변압기 1차/2차·차단기 AF/AT 등 모든 정격의 의미를 자동 확정한 기능이 아니다. 원본 종류와 기기 몸체 근거가 부정확한 경우의 일반화 정확도는 별도 도면 평가가 필요하다.

### 페이지 간 결선

페이지 참조 근처의 출발 기기와 유일한 호환 대상 쌍을 확인한다. 중복 태그·전압 충돌·용량만 있는 경우·출발 기기와 먼 참조는 자동 확정하지 않는다. 기기에 귀속된 확인 전압만 사용하고 V/kV를 같은 단위로 바꾼다. 여러 전압은 단자 역할 근거 없이는 첫 값을 고르지 않는다. 기존 정밀 연결의 허용 기준을 낮추지 않는다.

그래프 조립 버전은 v10이다. 과거 결과를 자동으로 새 정답으로 바꾼 것이 아니며 재분석 시 새 기준이 적용된다.

## 검증 설계

`reviewed-symbol-feedback.test.ts`는 실제 DXF 파서 → V3 adapter → deduplication → 정정 → 후보 → 승인 → 다음 파싱을 호출한다. 미승인·다른 회사·다른 이름·다른 형상·복수 원본·철회·충돌·가져오기·손상 저장·오래된 탭·모델 원문 provenance 위조의 음성 사례도 포함한다.

`rating-assignment-regression.test.ts`는 여러 정격, 귀속 동률/거리/페이지/태그, 손상 숫자·단위, 전압 정규화, 유일한 정상 연결, 중복 대상·문자 순서·먼 참조를 검사한다. 정상 양성 사례가 유지돼야 한다.

`feedback-quality.bench.ts`는 Git 이력에서 기준 production 함수를 읽어 같은 11개 진단을 기존/개선 코드에 적용한다. 추가로 승인용 합성 DXF 3개와 다른 위치·회전의 12개 문서(24개 INSERT), 이름·형상이 다른 음성 6개를 비교한다. 평가 스크립트는 원시 결과와 실제 production 소스 해시를 남긴다.

이 반복 DXF 시험은 동일 블록의 재사용 능력 검증이다. 독립 설계 도면 24개, AI 모델 재학습, 일반 도면 정답률 100%, 실제 미판독 30% 감소를 뜻하지 않는다. 실제 측정값은 실행 결과가 있을 때만 보고한다.

브라우저는 PC 1440px와 모바일 390px에서 정정·후보 저장·승인 전 미적용·다음 DXF 적용·새로고침 후 저장 유지·철회 후 미적용을 검사한다. 전송 응답은 합성이지만 파싱과 정정은 실제 함수를 실행한다. 기존 PDF/DXF·보고서·오류 복구 시험도 유지한다.
