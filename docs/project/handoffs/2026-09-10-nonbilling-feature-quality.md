출발 제품은 PR #71의 `dd4be8d5b39030390e23131adf3c442cd225da1c`다. 대화에서 기능 또는 상업성 평가가 8점 미만이었던 영역을 대상으로 했다. 그 점수는 주관적 제품 평가이지 정확도·완성률 측정값이 아니므로 숫자만 올려 작업을 종결하지 않는다. 실제 기능 연결·실패 복구·데이터/계정 범위·검증 근거를 개선한다.

## 공통 안전과 UI 계약

새 읽기 모델은 누락/손상된 목록을 빈 배열로 바꾸지 않는다. 변경 요청은 자동 재시도하지 않고 실패를 표시한다. 수동 재시도는 사용자 의도이며 서버에 반영됐는지 불명확한 네트워크 오류에서의 완전한 exactly-once 보증과 다르다. 계정 변경 후 렌더 단계에서도 기존 계정 키의 결과를 숨긴다. 인증 토큰은 요청 취소를 확인한 뒤 내부 API에만 보낸다.

CSV는 셀마다 따옴표와 구분자를 보존하고 수식으로 해석될 수 있는 선두 문자를 보호한다. 원문 링크는 일반 내부 경로 또는 자격증명 없는 HTTP(S)만 사용한다. 시간 정보가 없거나 잘못됐을 때 방금 전/오늘로 추정하지 않는다. 새 모달은 키보드 포커스를 내부에 유지하고 닫으면 원래 버튼으로 돌려준다. 전역 결제 UI나 도면 판독 화면을 무관하게 재설계하지 않는다.

## 검증과 실패 기록

초기 리소스 통합 smoke `34485723344`는 타입·무경고 린트·관련 검사를 통과했다. 후속 더 넓은 통합에서 단일 연결 객체의 제네릭 타입과 hook 의존성 경고를 발견해 수정했다. 전체 단위 실행 `34490892995`는 4,623통과/4실패였다. 새 SSE 필터 시험 JSON의 괄호 오타, 로컬 연결의 조용한 전환을 허용하던 옛 단언, 새로 보호된 현장 라우트의 오래된 예외 대장, 인증 로직 이동 후의 소스 단언을 각각 확인했다. 결제 예외를 추가하거나 기준을 낮춰 통과시키지 않았다.

명시 선택 정책의 변경은 image 지원 로컬 모델의 정상 경로를 유지하면서, 없는 경우 다른 공급자의 키를 읽지 않는 음성 검사로 고정한다. 현장 인증은 공통 모듈의 실제 실행 검사로 두 엔드포인트의 헤더·취소·익명 거부를 확인한다. 새로 방어한 라우트는 예외 목록에서 제거해 재유입을 차단한다.

새 단위 검사는 요청/응답/취소, 스코프·캐시 손상, SSE 완료/필터, RAG 라이선스·청크·실패·동시성, 알림/CSV 목적지, 명판/현장 기록, 관리자 권한/페이지를 포함한다. 실제 고객 계정·DB·결제·외부 AI 호출 없이 격리된 응답을 사용한다. 실패→수정 기록과 최종 결과는 실행별로 구분하고 기존 도면 회귀도 유지한다.

브라우저는 PC1440px/모바일390px에서 프로젝트 응답 역전, 대시보드 부분 조회, 커뮤니티 복구, 알림 읽음 실패, 관리자 전체 페이지/CSV, 손상 캐시와 계정 이력 실패, OCR 미판독 보완·원본 보존, 공유 모달 키보드, 기준 변환의 오래된 응답 차단을 검증한다. 캡처와 수평 넘침 검사 결과를 보관하되 자동 검사를 전체 화면 육안 심사 또는 접근성 인증이라고 부르지 않는다.
