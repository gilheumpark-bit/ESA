## 1. Product purpose

ESA는 전기 도면 한 장에서 기기·결선·계산·규정 검토 후보를 추출해 초보부터 고급 실무자까지 빠르게 확인하게 하는 전기 업무 보조 도구다.

## 2. Primary user

전기 업체·설계 사무소에서 1~20분 안에 도면의 누락과 확인 항목을 찾으려는 초보~고급 실무자가 데스크톱과 현장 모바일에서 반복 사용한다.

## 3. Principles

1. **분석은 ESA가 먼저 끝낸다.** 사용자에게 기기 수량이나 관계를 되묻지 않고, 판독 가능한 범위는 분석·판단·제안까지 제시한다.
2. **모르는 것은 숨기지 않는다.** HOLD·오류·미판독 근거는 선택한 탭과 무관하게 항상 보인다.
3. **초보는 요약부터, 고급자는 근거까지 간다.** 같은 결과를 요약→기기→결선→계산→검토 순으로 점진 공개한다.
4. **실제 결과가 화면의 중심이다.** 장식보다 도면에서 추출한 수량·관계·근거와 사용자의 다음 행동을 우선한다.

## 4. Success metric

사용자는 도면 업로드 후 첫 화면에서 분석 범위와 HOLD 여부를 파악하고, 한 번의 탭 선택으로 원하는 기기·결선·계산·검토 상세에 도달한다. 데스크톱과 390px 모바일 모두에서 결과 탭과 핵심 조작이 잘리거나 겹치지 않는다.

## 5. Out of scope

- 이 화면에서 CAD 도면을 직접 수정하거나 새 도면을 생성하지 않는다.
- 결과를 법적 승인이나 무조건적인 적합 판정으로 표현하지 않는다.
- 이번 변경에서 도면 판독·계산·규정 엔진의 알고리즘을 바꾸지 않는다.
- V3 전체 문서 보고서의 기존 탭 구조를 재설계하지 않는다.

## 6. Learned constraints

- **2026-08-26** — 빠른 분석 결과를 긴 세로 나열이 아니라 클릭 가능한 탭으로 보여 준다. *Why:* 한 장을 빠르게 확인하는 사용자가 필요한 상세만 바로 열어 업무 부하를 줄여야 한다.
- **2026-08-26** — UI 변경은 실제 도면 업로드 결과를 데스크톱·모바일에서 직접 보고 마무리한다. *Why:* 소스와 테스트만으로는 결과 길이·넘침·화면 밀도를 판단할 수 없다.
